📊 Sales Trend Analysis Project

🔹 Overview

This project is a web-based sales analysis system that helps visualize and understand sales data using interactive charts. It processes a dataset and generates insights like trends, profits, and top-performing products.

The project is built using Python for backend processing and a simple frontend interface for displaying results.

---

🔹 Features

- 📈 Sales Trend Visualization
- 🌍 Region-wise Sales Analysis
- 🛍️ Top Products Identification
- 💰 Profit Analysis
- 📊 Multiple Graphs Generation
- ⚡ Simple and user-friendly interface

---

🔹 Tech Stack

- Backend: Python (Flask, Pandas, Matplotlib)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite (.db file)
- Dataset: Superstore Sales Data

---

🔹 Project Structure

Sales_Trend_Project/

backend/ → Python backend (Flask, analysis)
frontend/ → UI files (HTML, CSS, JS)
graphs/ → Generated charts
Sales_Data.csv → Dataset
.gitignore → Ignored files

---

🔹 How to Run the Project

1. Clone the repository

2. Open project folder

3. Go to backend folder

4. Install dependencies:
   pip install flask pandas matplotlib

5. Run:
   python app.py

6. Open browser:
   http://127.0.0.1:5000

🔹 Output
